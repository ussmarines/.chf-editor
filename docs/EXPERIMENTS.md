# Protocole d'expérience

1. Partir d'une sauvegarde du jeu dont la provenance et le SHA-256 sont consignés. Garder l'original hors `outputs/`.
2. Relever le build exact de Star Citizen. Dans l'éditeur, modifier un seul contrôle et sauvegarder une seconde fois ; comparer les deux fichiers avec `diff`. Si plusieurs champs logiques bougent, on peut relier le geste au **groupe** de champs changé, mais le rôle individuel de chaque champ reste ambigu.
3. Pour une expérience binaire, créer une variante par `variant` (deux poids ADN compensés dans la même région, somme conservée) ou `variant-param` (un flottant matériel ou canal RGBA). La seconde commande exige SHA-256 source, indices et `name_hash` exacts. Le manifeste enregistre les SHA et le diff ; ne pas attribuer d'anatomie au `head_id` ou un contrôle UI à un nom de hash seul. Une paire enregistrée par BioCorp reste nécessaire pour comprendre le geste de l'interface.
4. Charger séparément la base et la variante dans le même build du jeu. **Après chaque import, ouvrir le personnage correspondant puis recliquer sur le sous-onglet à mesurer (Hair > Color peut afficher les valeurs du personnage précédent). Vérifier que le panneau s'est actualisé avant de relever un pourcentage ou une position de curseur.** Capturer face, profil et éclairage comparables. Noter la détection, le chargement, la stabilité et la possibilité de sauvegarde.
5. Renseigner `screenshots`, `game_version`, `game_load` et `visual_verdict` du manifeste local. Verdict autorisé : `effet confirmé`, `aucun effet visible`, `ambigu`, `non testé`. Ajouter les observations concrètes et conserver le fichier réenregistré séparément si le jeu le produit.

Une inspection réussie est seulement `STRUCTURAL_PASS`. Sur LIVE `4.10.193.11644`, les variantes `FrecklesOpacity` F02/M02 ont été chargées, comparées visuellement aux deux références et réenregistrées sous de nouveaux noms par BioCorp ; voir [l'essai détaillé](GAME_TEST_2026-09-27.md). Cette preuve ne couvre que ces champs, presets et build. Les changements supplémentaires du jeu lors de la sauvegarde sont conservés comme données opaques, sans signification supposée.
